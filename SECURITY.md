# Security Policy

## Supported versions

Security fixes are provided for the latest published version of each package:

| Package                               | Supported version        |
| ------------------------------------- | ------------------------ |
| `@heddendorp/effect-platform-angular` | Latest published version |
| `@heddendorp/effect-angular-query`    | Latest published version |
| Older versions of either package      | Not supported            |

Upgrade to the latest release before reporting a vulnerability that may already be fixed.

## Reporting a vulnerability

Report suspected vulnerabilities through the repository's
[private vulnerability reporting form](https://github.com/heddendorp/effect-angular/security/advisories/new).
This is the project's private security-reporting channel. Do not disclose vulnerability details
in a public issue, pull request, discussion, or social-media post.

Include enough information to reproduce and assess the issue:

- Affected package and version
- Impact and realistic attack scenario
- Reproduction steps or a minimal proof of concept
- Relevant configuration and dependency versions
- Any known workaround or suggested remediation

Continue follow-up in the private advisory thread. Maintainers will use that thread to confirm
receipt, request details, coordinate a fix, and agree on disclosure timing.

For ordinary defects without a security impact, open a
[public GitHub issue](https://github.com/heddendorp/effect-angular/issues/new).
